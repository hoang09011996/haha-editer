# vidflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Luồng nhiều agent trong Claude Code biến một ý tưởng thành draft CapCut Desktop (clip Veo + voice-over Gemini TTS + phụ đề + nhạc), có cổng duyệt ở mọi bước.

**Architecture:** CLI Python `vidflow` làm mọi việc xác định (gọi Gemini, lưu trạng thái, dựng draft qua pyCapCut) trên một thư mục project (`script.yaml` + `state.json`). Phiên Claude Code chính đóng vai director (skill `vidflow-director` + `CLAUDE.md`) và gọi 5 subagent (`.claude/agents/`) — subagent của Claude Code không gọi được subagent khác, nên director không phải là subagent.

**Tech Stack:** Python 3.11+, uv, Typer, Pydantic v2, PyYAML, google-genai, pycapcut 0.0.3, pytest, ffmpeg/ffprobe.

**Spec:** `docs/superpowers/specs/2026-09-28-vidflow-design.md`

## Global Constraints

- Python `>=3.11`; quản lý bằng `uv`; package ở `src/vidflow/`, test ở `tests/`.
- Tỉ lệ khung hình chỉ `"9:16"` hoặc `"16:9"`; canvas 1080x1920 / 1920x1080.
- Veo `duration` chỉ 4, 6 hoặc 8 giây; tối đa 3 ảnh tham chiếu mỗi cảnh; `veo_resolution` ∈ `720p|1080p|4k`.
- Model mặc định: `veo-3.1-generate-preview`, `gemini-3.8-flash-tts`; `image_model` và `veo_price_per_second` không có mặc định — người dùng đặt trong `vidflow.toml`.
- Độ dài cảnh = độ dài lời dẫn + 0.3s; clip ngắn hơn → giảm tốc tối đa 0.8x; vẫn thiếu → bỏ cảnh và báo lý do.
- Chỉ cảnh `status: approved` được gen video; `gen` từ chối nếu `spent_usd + dự kiến > budget_usd`.
- Không ghi draft khi CapCut đang chạy; backup draft cũ vào `projects/<p>/backups/<timestamp>/` trước khi ghi đè; tên draft `vidflow_<tên thư mục project>`.
- API key chỉ đọc từ `GEMINI_API_KEY` (hoặc `GOOGLE_API_KEY`), không ghi vào project.
- Thông báo cho người dùng bằng tiếng Việt; lỗi người dùng gây ra đi qua `VidflowError` và in ra không có traceback.
- Test không gọi API thật.

## Review Focus

1. Tiến trình bị dừng giữa lúc chờ Veo → chạy lại `gen` tiếp tục poll job cũ, không tạo job/chi phí trùng (test: Task 5 `test_resume_pending_without_resubmit`).
2. Veo trả về không có video (bị lọc an toàn) → ghi lỗi vào cảnh, các cảnh khác vẫn chạy, không tính tiền (test: Task 5 `test_filtered_scene_records_error_and_others_continue`).
3. TTS trả PCM thô thay vì WAV → bọc thành WAV 24kHz mono 16-bit, thời lượng đúng (test: Task 4 `test_raw_pcm_is_wrapped`).
4. Lời dẫn có từ dài hơn `max_chars_per_line`, hoặc lời dẫn rỗng → tách cứng; cảnh không lời dẫn dùng độ dài clip, không có voice/phụ đề (test: Task 8 `test_split_hard_wraps_long_word`, `test_scene_without_narration_uses_clip_length`).
5. Làm tròn micro-giây làm các segment chồng nhau khiến pyCapCut báo lỗi → biên dùng chung giữa segment liền kề (test: Task 9 `test_build_slowed_scenes_and_subtitles_no_overlap`).

```python
"""Tạo draft thử 'vidflow_probe' (9:16) với video, voice, nhạc, text để mở trong CapCut 9.5."""
import subprocess
import sys
from pathlib import Path

import pycapcut as cc
from pycapcut import trange_seconds

OUT = Path(__file__).parent / "out"
OUT.mkdir(exist_ok=True)
DRAFTS = Path.home() / "Movies/CapCut/User Data/Projects/com.lveditor.draft"

video = OUT / "probe.mp4"
tone = OUT / "probe.wav"
subprocess.run(["ffmpeg", "-y", "-loglevel", "error", "-f", "lavfi", "-i", "testsrc=size=1080x1920:rate=30",
                "-t", "4", "-pix_fmt", "yuv420p", str(video)], check=True)
subprocess.run(["ffmpeg", "-y", "-loglevel", "error", "-f", "lavfi", "-i", "sine=frequency=440:sample_rate=24000",
                "-t", "3", "-ac", "1", str(tone)], check=True)

if subprocess.run(["pgrep", "-x", "CapCut"], capture_output=True).returncode == 0:
    sys.exit("Thoát CapCut trước khi chạy probe.")

folder = cc.DraftFolder(str(DRAFTS))
draft = folder.create_draft("vidflow_probe", 1080, 1920, allow_replace=True)
draft.add_track(cc.TrackType.video)
draft.add_track(cc.TrackType.audio, "voice")
draft.add_track(cc.TrackType.audio, "music")
draft.add_track(cc.TrackType.text, "subs")
draft.add_segment(cc.VideoSegment(str(video), trange_seconds(0, duration=3.5),
                                  source_timerange=trange_seconds(0, duration=3.0), speed=3.0 / 3.5, volume=0.0))
draft.add_segment(cc.AudioSegment(str(tone), trange_seconds(0, duration=3.0)), "voice")
music = cc.AudioMaterial(str(tone))
print("AudioMaterial.duration (µs):", music.duration)
draft.add_segment(cc.AudioSegment(music, trange_seconds(0, duration=3.0), volume=0.15), "music")
draft.add_segment(cc.TextSegment("Xin chào vidflow — tiếng Việt có dấu", trange_seconds(0, duration=3.5),
                                 style=cc.TextStyle(size=8.0, align=1, auto_wrapping=True),
                                 clip_settings=cc.ClipSettings(transform_y=-0.7)), "subs")
draft.save()
print("Đã tạo draft:", DRAFTS / "vidflow_probe")
```

```python
"""Xác minh Gemini: liệt kê model, TTS tiếng Việt, (tùy chọn) Veo lite 4s."""
import base64
import sys
import time
from pathlib import Path

from google import genai
from google.genai import types

OUT = Path(__file__).parent / "out"
OUT.mkdir(exist_ok=True)
client = genai.Client()

print("== Models")
for m in client.models.list():
    name = m.name or ""
    if any(k in name for k in ("veo", "tts", "image")):
        print(name)

print("== TTS")
print("has interactions API:", hasattr(client, "interactions"))
it = client.interactions.create(
    model="gemini-3.8-flash-tts",
    input=[{"type": "user_input", "content": [{"type": "text", "text": "Mỗi sáng, An bắt đầu ngày mới bằng một tách cà phê."}]}],
    response_format={"type": "audio"},
    generation_config={"speech_config": [{"voice": "Kore"}]},
)
audio = base64.b64decode(it.output_audio.data)
print("audio header:", audio[:4])
(OUT / "tts.wav").write_bytes(audio)

if "--veo" in sys.argv:
    print("== Veo lite 4s (TỐN PHÍ)")
    op = client.models.generate_videos(
        model="veo-3.1-lite-generate-preview",
        prompt="A cup of coffee on a wooden table, morning light, slow push-in.",
        config=types.GenerateVideosConfig(aspect_ratio="9:16", duration_seconds=4, resolution="720p"),
    )
    print("operation name:", op.name)
    while not op.done:
        time.sleep(10)
        op = client.operations.get(types.GenerateVideosOperation(name=op.name))
    vids = op.response.generated_videos or []
    print("videos:", len(vids), "filtered:", getattr(op.response, "rai_media_filtered_reasons", None))
    client.files.download(file=vids[0].video)
    vids[0].video.save(str(OUT / "veo.mp4"))
    print("saved", OUT / "veo.mp4")
```

```python
from pydantic import ValidationError

from vidflow.schema import Script


def base(**over):
    data = {"title": "T", "scenes": [{"id": "s01"}]}

    return data

    s = Script.model_validate(base())
    assert s.aspect == "9:16"
    assert s.voice.name == "Kore"

    assert s.scenes[0].status == "draft"

    with pytest.raises(ValidationError):

    with pytest.raises(ValidationError, match="trùng"):
```

```python
from __future__ import annotations

from typing import Literal

from pydantic import BaseModel, Field, model_validator

from vidflow.errors import ScriptError

Aspect = Literal["9:16", "16:9"]


class Character(BaseModel):
    id: str = Field(pattern=r"^[a-z0-9_]+$")
    description: str
    ref_image: str | None = None


class Voice(BaseModel):
    name: str = "Kore"
    style: str = ""
    speed: float = Field(1.0, gt=0.5, le=2.0)


class Music(BaseModel):
    file: str
    volume: float = Field(0.15, ge=0, le=1)


class Subtitles(BaseModel):
    enabled: bool = True
    max_chars_per_line: int = Field(32, ge=8)


class Scene(BaseModel):
    id: str = Field(pattern=r"^[a-z0-9_]+$")
    narration: str = ""
    veo_prompt: str = ""
    characters: list[str] = []
    duration: Literal[4, 6, 8] = 8
    veo_audio: bool = False
    status: Literal["draft", "approved"] = "draft"


class Script(BaseModel):
    title: str
    aspect: Aspect = "9:16"
    style: str = ""
    characters: list[Character] = []
    voice: Voice = Voice()
    music: Music | None = None
    subtitles: Subtitles = Subtitles()
    budget_usd: float = Field(20, gt=0)
    scenes: list[Scene] = []

    @model_validator(mode="after")
    def _check_refs(self) -> "Script":
        ids = [s.id for s in self.scenes]
        dup = sorted({i for i in ids if ids.count(i) > 1})
        if dup:
            raise ValueError(f"scene id trùng: {dup}")
        char_ids = {c.id for c in self.characters}
        for s in self.scenes:
            unknown = sorted(set(s.characters) - char_ids)
            if unknown:
                raise ValueError(f"scene {s.id}: nhân vật không tồn tại {unknown}")
        return self

    def scene(self, scene_id: str) -> Scene:
        for s in self.scenes:
            if s.id == scene_id:
                return s
        raise ScriptError(f"Không có cảnh '{scene_id}' trong script.yaml")

    def character(self, char_id: str) -> Character:
        for c in self.characters:
            if c.id == char_id:
                return c
        raise ScriptError(f"Không có nhân vật '{char_id}' trong script.yaml")
```

```python
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=path.name, suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as f:
```

```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import yaml
from pydantic import ValidationError

from vidflow.errors import ScriptError
from vidflow.schema import Character, Script
from vidflow.state import ProjectState, atomic_write_text

SUBDIRS = ("audio", "clips", "refs", "music", "logs")
REF_EXTS = (".png", ".jpg", ".jpeg")

TEMPLATE = """\
title: "{title}"
aspect: "{aspect}"
style: ""
characters: []
voice: {{ name: "Kore", style: "", speed: 1.0 }}
music: null
subtitles: {{ enabled: true, max_chars_per_line: 32 }}
budget_usd: 20
scenes: []
"""


@dataclass(frozen=True)
class Project:
    root: Path

    @property
    def script_path(self) -> Path:
        return self.root / "script.yaml"

    @property
    def state_path(self) -> Path:
        return self.root / "state.json"

    @property
    def audio_dir(self) -> Path:
        return self.root / "audio"

    @property
    def clips_dir(self) -> Path:
        return self.root / "clips"

    @property
    def refs_dir(self) -> Path:
        return self.root / "refs"

    @property
    def backups_dir(self) -> Path:
        return self.root / "backups"

    @classmethod
    def open(cls, root: Path) -> "Project":
        root = Path(root).resolve()
        if not (root / "script.yaml").is_file():
            raise ScriptError(f"Không thấy {root / 'script.yaml'}. Tạo bằng: vidflow new {root} --title \"...\"")
        return cls(root)

    def load_script(self) -> Script:
        try:
            data = yaml.safe_load(self.script_path.read_text(encoding="utf-8")) or {}
        except yaml.YAMLError as e:
            raise ScriptError(f"script.yaml sai cú pháp YAML: {e}") from e
        try:
            return Script.model_validate(data)
        except ValidationError as e:
            raise ScriptError(f"script.yaml không hợp lệ:\n{e}") from e

    def load_state(self) -> ProjectState:
        if not self.state_path.is_file():
            return ProjectState()
        return ProjectState.model_validate_json(self.state_path.read_text(encoding="utf-8"))

    def save_state(self, state: ProjectState) -> None:
        atomic_write_text(self.state_path, state.model_dump_json(indent=2))

    def path(self, rel: str) -> Path:
        return self.root / rel

    def rel(self, path: Path) -> str:
        return Path(path).resolve().relative_to(self.root).as_posix()

    def ref_image(self, character: Character) -> Path | None:
        if character.ref_image:
            p = self.path(character.ref_image)
            if not p.is_file():
                raise ScriptError(f"Nhân vật {character.id}: không thấy ảnh {character.ref_image}")
            return p
        for ext in REF_EXTS:
            p = self.refs_dir / f"{character.id}{ext}"
            if p.is_file():
                return p
        return None


def create_project(root: Path, title: str, aspect: str) -> Project:
    root = Path(root).resolve()
    if (root / "script.yaml").exists():
        raise ScriptError(f"{root} đã có script.yaml")
    if aspect not in ("9:16", "16:9"):
        raise ScriptError(f"aspect phải là 9:16 hoặc 16:9, nhận '{aspect}'")
    for d in SUBDIRS:
        (root / d).mkdir(parents=True, exist_ok=True)
    safe_title = title.replace("\\", "\\\\").replace('"', '\\"')
    (root / "script.yaml").write_text(TEMPLATE.format(title=safe_title, aspect=aspect), encoding="utf-8")
    return Project(root)
```

```python
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        try:
            return fn(*args, **kwargs)
        except VidflowError as e:
            typer.secho(str(e), fg=typer.colors.RED, err=True)
            raise typer.Exit(1)

    return app.command()(wrapper)

    root: Annotated[Path, typer.Argument(help="Thư mục project mới")],

    typer.echo(f"Đã tạo {p.script_path}")


@command

    script = Project.open(project).load_script()
```

```python
import tomllib
from dataclasses import fields

from vidflow.errors import ConfigError

RESOLUTIONS = ("720p", "1080p", "4k")


def load_config(path: Path | None = None) -> Config:
    path = Path(path) if path else Path("vidflow.toml")
    if not path.is_file():
        return Config()
    try:
        data = tomllib.loads(path.read_text(encoding="utf-8"))
    except tomllib.TOMLDecodeError as e:
        raise ConfigError(f"{path}: sai cú pháp TOML: {e}") from e
    unknown = sorted(set(data) - {f.name for f in fields(Config)})
    if unknown:
        raise ConfigError(f"{path}: khóa không hỗ trợ {unknown}")
    if data.get("image_model") == "":
        data["image_model"] = None
    if data.get("veo_price_per_second") in (0, 0.0):
        data["veo_price_per_second"] = None
    if "draft_folder" in data:
        data["draft_folder"] = Path(data["draft_folder"]).expanduser()
    if data.get("veo_resolution", "720p") not in RESOLUTIONS:
        raise ConfigError(f"{path}: veo_resolution phải thuộc {RESOLUTIONS}")
    return Config(**data)
```

```python
from __future__ import annotations

import hashlib
import json
from pathlib import Path

from vidflow.config import Config
from vidflow.errors import ScriptError
from vidflow.project import Project
from vidflow.schema import Scene, Script

SCENE_PAD_S = 0.3
MIN_CLIP_SPEED = 0.8
MAX_REF_IMAGES = 3


def _digest(obj) -> str:
    raw = json.dumps(obj, sort_keys=True, ensure_ascii=False).encode("utf-8")
    return hashlib.sha256(raw).hexdigest()[:16]


def _file_digest(path: Path) -> str:
    return hashlib.sha256(path.read_bytes()).hexdigest()[:16]


def compose_veo_prompt(script: Script, scene: Scene) -> str:
    parts: list[str] = []
    if script.style:
        parts.append(f"Style: {script.style}.")
    for cid in scene.characters:
        parts.append(f"{cid}: {script.character(cid).description}.")
    parts.append(scene.veo_prompt.strip())
    if not scene.veo_audio:
        parts.append("No dialogue, no narration, no music.")
    return " ".join(parts)


def scene_ref_images(project: Project, script: Script, scene: Scene) -> list[Path]:
    refs = [p for cid in scene.characters if (p := project.ref_image(script.character(cid))) is not None]
    if len(refs) > MAX_REF_IMAGES:
        raise ScriptError(f"Cảnh {scene.id}: Veo nhận tối đa 3 ảnh tham chiếu, đang có {len(refs)}")
    return refs


def tts_hash(script: Script, scene: Scene, cfg: Config) -> str:
    return _digest({"text": scene.narration, "voice": script.voice.name,
                    "style": script.voice.style, "model": cfg.tts_model})


def video_hash(project: Project, script: Script, scene: Scene, cfg: Config) -> str:
    return _digest({
        "prompt": compose_veo_prompt(script, scene),
        "duration": scene.duration,
        "aspect": script.aspect,
        "model": cfg.veo_model,
        "resolution": cfg.veo_resolution,
        "refs": [_file_digest(p) for p in scene_ref_images(project, script, scene)],
    })
```

```python
from __future__ import annotations

from dataclasses import dataclass, field

from vidflow.config import Config
from vidflow.errors import BudgetError, ConfigError, ScriptError
from vidflow.inputs import video_hash
from vidflow.project import Project
from vidflow.schema import Script
from vidflow.state import ProjectState, SceneState


@dataclass(frozen=True)
class GenJob:
    scene_id: str
    input_hash: str
    seconds: int


@dataclass(frozen=True)
class Estimate:
    jobs: list[GenJob]
    seconds: int
    usd: float
    skipped: dict[str, str] = field(default_factory=dict)


def plan_gen(project: Project, script: Script, state: ProjectState, cfg: Config, *,
             scene_ids: list[str] | None = None, takes: int = 1, force: bool = False) -> Estimate:
    if cfg.veo_price_per_second is None:
        raise ConfigError("Chưa đặt veo_price_per_second trong vidflow.toml "
                          "(USD/giây, lấy theo bảng giá Veo hiện hành của Google).")
    if takes < 1:
        raise ScriptError("--takes phải >= 1")
    selected = script.scenes if not scene_ids else [script.scene(i) for i in scene_ids]
    jobs: list[GenJob] = []
    skipped: dict[str, str] = {}
    for scene in selected:
        if scene.status != "approved":
            skipped[scene.id] = "chưa approved"
            continue
        if not scene.veo_prompt.strip():
            skipped[scene.id] = "veo_prompt trống"
            continue
        h = video_hash(project, script, scene, cfg)
        st = state.scenes.get(scene.id) or SceneState()
        have = sum(t.input_hash == h for t in st.takes) + sum(p.input_hash == h for p in st.pending)
        need = takes if force else max(0, takes - have)
        if need == 0:
            skipped[scene.id] = "đã có clip khớp prompt hiện tại"
            continue
        jobs.extend(GenJob(scene.id, h, scene.duration) for _ in range(need))
    seconds = sum(j.seconds for j in jobs)
    return Estimate(jobs=jobs, seconds=seconds, usd=round(seconds * cfg.veo_price_per_second, 2), skipped=skipped)


def check_budget(script: Script, state: ProjectState, est: Estimate) -> None:
    if state.spent_usd + est.usd > script.budget_usd:
        raise BudgetError(
            f"Vượt ngân sách: đã tiêu {state.spent_usd:.2f} + dự kiến {est.usd:.2f} > budget {script.budget_usd:.2f} USD. "
            "Tăng budget_usd trong script.yaml hoặc bớt cảnh."
        )
```

```python
from __future__ import annotations

import time
from typing import Callable, TypeVar

T = TypeVar("T")
TRANSIENT_CODES = {429, 500, 502, 503, 504}


def is_transient(exc: BaseException) -> bool:
    if isinstance(exc, (ConnectionError, TimeoutError)):
        return True
    return getattr(exc, "code", None) in TRANSIENT_CODES


def with_retry(fn: Callable[[], T], *, attempts: int = 3, base_delay: float = 2.0,
               sleep: Callable[[float], None] = time.sleep) -> T:
    for i in range(attempts):
        try:
            return fn()
        except Exception as exc:
            if i == attempts - 1 or not is_transient(exc):
                raise
            sleep(base_delay * 2 ** i)
    raise AssertionError("unreachable")
```

```python
from __future__ import annotations

import io
import math
import subprocess
import wave
from pathlib import Path

from vidflow.errors import VidflowError


def ensure_wav(data: bytes, rate: int = 24000) -> bytes:
    """Gemini TTS trả WAV; nếu nhận PCM 16-bit mono thô thì bọc header WAV."""
    if data[:4] == b"RIFF":
        return data
    buf = io.BytesIO()
    with wave.open(buf, "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(rate)
        w.writeframes(data)
    return buf.getvalue()


def wav_duration(path: Path) -> float:
    with wave.open(str(path), "rb") as w:
        return w.getnframes() / w.getframerate()


def floor_ms(x: float) -> float:
    return math.floor(x * 1000) / 1000


def probe_duration(path: Path) -> float:
    r = subprocess.run(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration", "-of", "csv=p=0", str(path)],
        capture_output=True, text=True,
    )
    if r.returncode != 0 or not r.stdout.strip():
        raise VidflowError(f"ffprobe không đọc được {path}: {r.stderr.strip()}")
    return float(r.stdout.strip())
```

```python
from __future__ import annotations

import time
from typing import Callable, Protocol

from vidflow.config import Config
from vidflow.inputs import tts_hash
from vidflow.media import ensure_wav, floor_ms, wav_duration
from vidflow.project import Project
from vidflow.retry import with_retry
from vidflow.state import TtsResult


class SpeechClient(Protocol):
    def synthesize(self, *, text: str, voice: str, style: str, model: str) -> bytes: ...


def run_tts(project: Project, cfg: Config, client: SpeechClient, *, scene_ids: list[str] | None = None,
            force: bool = False, sleep: Callable[[float], None] = time.sleep) -> list[str]:
    script, state = project.load_script(), project.load_state()
    selected = script.scenes if not scene_ids else [script.scene(i) for i in scene_ids]
    done: list[str] = []
    for scene in selected:
        if not scene.narration.strip():
            continue
        h = tts_hash(script, scene, cfg)
        st = state.scene(scene.id)
        if not force and st.tts and st.tts.input_hash == h and project.path(st.tts.file).is_file():
            continue
        data = with_retry(lambda: client.synthesize(text=scene.narration, voice=script.voice.name,
                                                    style=script.voice.style, model=cfg.tts_model), sleep=sleep)
        out = project.audio_dir / f"{scene.id}.wav"
        out.write_bytes(ensure_wav(data))
        st.tts = TtsResult(file=project.rel(out), duration_s=floor_ms(wav_duration(out)), input_hash=h)
        project.save_state(state)
        done.append(scene.id)
    return done
```

```python
class FakeVeo:
    """Mỗi job cần `polls_needed` lần poll; scene nào có trong `filtered` trả lỗi."""

    def __init__(self, polls_needed=2, filtered=()):
        self.polls_needed = polls_needed
        self.filtered = set(filtered)
        self.submitted = []
        self.poll_count = {}

    def submit(self, *, prompt, aspect, duration, resolution, model, ref_images):
        name = f"op{len(self.submitted) + 1}"
        self.submitted.append({"name": name, "prompt": prompt, "duration": duration, "aspect": aspect})
```

```python
from __future__ import annotations

import time
from dataclasses import dataclass, field
from datetime import datetime, timezone
from pathlib import Path
from typing import Any, Callable, Protocol

from vidflow.config import Config
from vidflow.cost import check_budget, plan_gen
from vidflow.errors import ScriptError, VidflowError
from vidflow.inputs import compose_veo_prompt, scene_ref_images
from vidflow.project import Project
from vidflow.retry import with_retry
from vidflow.state import PendingOp, Take


@dataclass
class PollResult:
    done: bool
    video: Any = None
    error: str | None = None


class VideoClient(Protocol):
    def submit(self, *, prompt: str, aspect: str, duration: int, resolution: str, model: str,
               ref_images: list[Path]) -> str: ...

    def poll(self, op_name: str) -> PollResult: ...

    def download(self, video: Any, dest: Path) -> None: ...


@dataclass
class GenReport:
    created: list[str] = field(default_factory=list)
    failed: dict[str, str] = field(default_factory=dict)


def _now_iso() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


def run_gen(project: Project, cfg: Config, client: VideoClient, *, scene_ids: list[str] | None = None,
            takes: int = 1, force: bool = False, poll_interval: float = 10.0, timeout_s: float = 900.0,
            sleep: Callable[[float], None] = time.sleep, clock: Callable[[], float] = time.monotonic,
            now: Callable[[], str] = _now_iso) -> GenReport:
    script, state = project.load_script(), project.load_state()
    est = plan_gen(project, script, state, cfg, scene_ids=scene_ids, takes=takes, force=force)
    check_budget(script, state, est)
    scenes = {s.id: s for s in script.scenes}
    report = GenReport()

    for job in est.jobs:
        scene = scenes[job.scene_id]
        op_name = with_retry(lambda: client.submit(
            prompt=compose_veo_prompt(script, scene), aspect=script.aspect, duration=scene.duration,
            resolution=cfg.veo_resolution, model=cfg.veo_model,
            ref_images=scene_ref_images(project, script, scene)), sleep=sleep)
        state.scene(job.scene_id).pending.append(
            PendingOp(name=op_name, input_hash=job.input_hash, seconds=job.seconds, submitted_at=now()))
        project.save_state(state)

    wanted = set(scene_ids) if scene_ids else set(scenes)
    deadline = clock() + timeout_s
    while True:
        open_ops = [(sid, op) for sid, st in state.scenes.items() if sid in wanted for op in list(st.pending)]
        if not open_ops:
            return report
        for sid, op in open_ops:
            res = with_retry(lambda: client.poll(op.name), sleep=sleep)
            if not res.done:
                continue
            st = state.scene(sid)
            st.pending.remove(op)
            if res.error:
                st.errors.append(f"{now()} {res.error}")
                report.failed[sid] = res.error
            else:
                dest = project.clips_dir / f"{sid}_t{len(st.takes) + 1}.mp4"
                with_retry(lambda: client.download(res.video, dest), sleep=sleep)
                cost = round(op.seconds * cfg.veo_price_per_second, 4)
                st.takes.append(Take(file=project.rel(dest), input_hash=op.input_hash, cost_usd=cost,
                                     created_at=now()))
                state.spent_usd = round(state.spent_usd + cost, 4)
                if st.picked is None or st.takes[st.picked].input_hash != op.input_hash:
                    st.picked = len(st.takes) - 1
                report.created.append(project.rel(dest))
            project.save_state(state)
        if any(st.pending for sid, st in state.scenes.items() if sid in wanted):
            if clock() > deadline:
                raise VidflowError("Hết thời gian chờ Veo; chạy lại `vidflow gen` để tiếp tục chờ (job không bị tạo lại).")
            sleep(poll_interval)


def pick_take(project: Project, scene_id: str, take_number: int) -> str:
    project.load_script().scene(scene_id)
    state = project.load_state()
    st = state.scene(scene_id)
    if not 1 <= take_number <= len(st.takes):
        raise ScriptError(f"Cảnh {scene_id} có take 1..{len(st.takes)}, nhận {take_number}")
    st.picked = take_number - 1
    project.save_state(state)
    return st.takes[st.picked].file
```

```python
from pathlib import Path

from vidflow.video import PollResult


class GeminiVideoClient:
    def __init__(self, client=None):
        self._c = client or gemini_client()

    def submit(self, *, prompt, aspect, duration, resolution, model, ref_images: list[Path]) -> str:
        from google.genai import types

        refs = [types.VideoGenerationReferenceImage(image=types.Image.from_file(location=str(p)),
                                                    reference_type="asset") for p in ref_images]
        op = self._c.models.generate_videos(
            model=model,
            prompt=prompt,
            config=types.GenerateVideosConfig(aspect_ratio=aspect, duration_seconds=duration,
                                              resolution=resolution, reference_images=refs or None),
        )
        return op.name

    def poll(self, op_name: str) -> PollResult:
        from google.genai import types

        op = self._c.operations.get(types.GenerateVideosOperation(name=op_name))
        if not op.done:
            return PollResult(done=False)
        if op.error:
            return PollResult(done=True, error=f"Veo lỗi: {op.error}")
        vids = (op.response.generated_videos if op.response else None) or []
        if not vids:
            reasons = getattr(op.response, "rai_media_filtered_reasons", None)
            return PollResult(done=True, error=f"Veo không trả video (có thể bị lọc an toàn): {reasons}")
        return PollResult(done=True, video=vids[0].video)

    def download(self, video, dest: Path) -> None:
        self._c.files.download(file=video)
        video.save(str(dest))
```

```python
from __future__ import annotations

import time
from typing import Callable, Protocol

from vidflow.config import Config
from vidflow.errors import ConfigError
from vidflow.project import REF_EXTS, Project
from vidflow.retry import with_retry
from vidflow.schema import Character, Script


class ImageClient(Protocol):
    def generate(self, *, prompt: str, model: str) -> bytes: ...


def character_prompt(script: Script, character: Character) -> str:
    style = f" Visual style: {script.style}." if script.style else ""
    return ("Character reference sheet on a plain neutral background, one person, front view, "
            f"face and full outfit clearly visible: {character.description}.{style}")


def _ext(data: bytes) -> str:
    return ".jpg" if data[:3] == b"\xff\xd8\xff" else ".png"


def run_refimg(project: Project, cfg: Config, client: ImageClient, *, character_ids: list[str] | None = None,
               force: bool = False, sleep: Callable[[float], None] = time.sleep) -> list[str]:
    if not cfg.image_model:
        raise ConfigError("Chưa đặt image_model trong vidflow.toml.")
    script = project.load_script()
    chars = script.characters if not character_ids else [script.character(c) for c in character_ids]
    created: list[str] = []
    for c in chars:
        if not force and project.ref_image(c) is not None:
            continue
        data = with_retry(lambda: client.generate(prompt=character_prompt(script, c), model=cfg.image_model),
                          sleep=sleep)
        for ext in REF_EXTS:
            (project.refs_dir / f"{c.id}{ext}").unlink(missing_ok=True)
        out = project.refs_dir / f"{c.id}{_ext(data)}"
        out.write_bytes(data)
        created.append(project.rel(out))
    return created
```

```python
CSS = """
body{font-family:Arial,sans-serif;margin:16px;background:#fff;color:#111}
h1{color:#000080} .scene{border:1px solid #ccd;border-radius:8px;padding:12px;margin:12px 0}

video{max-width:280px;max-height:420px;background:#000} .picked figcaption{color:#1fba00;font-weight:bold}
.err{color:#b00} .meta{color:#0069ba}
"""


def _scene_html(scene, st: SceneState) -> str:
    parts = [f'<section class="scene"><h2>{escape(scene.id)} <span class="meta">[{scene.status}, {scene.duration}s]</span></h2>',
             f"<p><b>Lời dẫn:</b> {escape(scene.narration) or '<i>(không)</i>'}</p>",
             f"<p><b>Prompt:</b> {escape(scene.veo_prompt)}</p>"]
    if st.tts:
        parts.append(f'<audio controls src="{escape(st.tts.file)}"></audio> {st.tts.duration_s:.2f}s')
    parts.append('<div class="takes">')
    for i, t in enumerate(st.takes):
        picked = i == st.picked
        label = f"take {i + 1}" + (" (đang chọn)" if picked else "")
        parts.append(f'<figure class="{"picked" if picked else ""}"><video controls src="{escape(t.file)}"></video>'
                     f"<figcaption>{label}</figcaption></figure>")
    parts.append("</div>")
    parts.extend(f'<p class="err">{escape(e)}</p>' for e in st.errors[-3:])
    parts.append("</section>")
    return "\n".join(parts)


def render_preview(project: Project, script: Script, state: ProjectState) -> Path:
    body = "\n".join(_scene_html(s, state.scenes.get(s.id) or SceneState()) for s in script.scenes)
    html = (f'<!doctype html><html lang="vi"><head><meta charset="utf-8"><title>{escape(script.title)}</title>'
            f"<style>{CSS}</style></head><body><h1>{escape(script.title)}</h1>"
            f"<p class=\"meta\">{script.aspect} · đã tiêu {state.spent_usd:.2f}/{script.budget_usd:.2f} USD</p>"
```

```python
def scene_rows(project: Project, script: Script, state: ProjectState, cfg: Config) -> list[dict[str, str]]:
    rows = []
    for scene in script.scenes:
```

```python
from __future__ import annotations

from dataclasses import dataclass

from vidflow.inputs import MIN_CLIP_SPEED, SCENE_PAD_S
from vidflow.media import floor_ms
from vidflow.schema import Script
from vidflow.state import ProjectState


@dataclass(frozen=True)
class Subtitle:
    start: float
    end: float
    text: str


@dataclass(frozen=True)
class ScenePlan:
    scene_id: str
    start: float
    end: float
    clip: str
    clip_len: float      # độ dài lấy từ clip nguồn (giây)
    clip_speed: float
    clip_volume: float
    voice: str | None
    voice_len: float     # độ dài voice trên timeline (giây, đã tính speed)
    voice_speed: float
    subtitles: tuple[Subtitle, ...]


@dataclass(frozen=True)
class Timeline:
    scenes: tuple[ScenePlan, ...]
    skipped: dict[str, str]
    total: float


def split_subtitle(text: str, max_chars: int) -> list[str]:
    lines: list[str] = []
    cur = ""
    for w in text.split():
        while len(w) > max_chars:
            if cur:
                lines.append(cur)
                cur = ""
            lines.append(w[:max_chars])
            w = w[max_chars:]
        if not w:
            continue
        cand = f"{cur} {w}" if cur else w
        if len(cand) <= max_chars:
            cur = cand
        else:
            lines.append(cur)
            cur = w
    if cur:
        lines.append(cur)
    return lines


def _subtitles(text: str, max_chars: int, start: float, voice_len: float) -> tuple[Subtitle, ...]:
    lines = split_subtitle(text, max_chars)
    total = sum(len(l) for l in lines)
    out, acc = [], 0
    for line in lines:
        s = round(start + voice_len * acc / total, 3)
        acc += len(line)
        e = round(start + voice_len * acc / total, 3)
        out.append(Subtitle(s, e, line))
    return tuple(out)


def plan_timeline(script: Script, state: ProjectState, clip_durations: dict[str, float], *,
                  pad: float = SCENE_PAD_S, min_speed: float = MIN_CLIP_SPEED) -> Timeline:
    t = 0.0
    plans: list[ScenePlan] = []
    skipped: dict[str, str] = {}
    for scene in script.scenes:
        if scene.status != "approved":
            skipped[scene.id] = "chưa approved"
            continue
        st = state.scenes.get(scene.id)
        if st is None or st.picked is None:
            skipped[scene.id] = "chưa có clip"
            continue
        clip = st.takes[st.picked].file
        clip_len = floor_ms(clip_durations[clip])
        has_voice = bool(scene.narration.strip())
        if has_voice and st.tts is None:
            skipped[scene.id] = "chưa có voice-over"
            continue
        voice_len = floor_ms(st.tts.duration_s / script.voice.speed) if has_voice else 0.0
        length = round(voice_len + pad, 3) if has_voice else clip_len
        if clip_len >= length:
            speed, src = 1.0, length
        else:
            speed = clip_len / length
            if speed < min_speed:
                skipped[scene.id] = (f"lời dẫn {length:.1f}s dài hơn clip {clip_len:.1f}s "
                                     f"(cần tốc độ {speed:.2f} < {min_speed})")
                continue
            src = clip_len
        start, end = round(t, 3), round(t + length, 3)
        subs = _subtitles(scene.narration, script.subtitles.max_chars_per_line, start, voice_len) \
            if has_voice and script.subtitles.enabled else ()
        plans.append(ScenePlan(
            scene_id=scene.id, start=start, end=end, clip=clip, clip_len=src, clip_speed=speed,
            clip_volume=1.0 if scene.veo_audio else 0.0,
            voice=st.tts.file if has_voice else None, voice_len=voice_len, voice_speed=script.voice.speed,
            subtitles=subs,
        ))
        t = end
    return Timeline(scenes=tuple(plans), skipped=skipped, total=round(t, 3))
```

```python
from __future__ import annotations

import math
import shutil
import subprocess
from datetime import datetime, timezone
from pathlib import Path
from typing import Callable

import pycapcut as cc

from vidflow.config import Config
from vidflow.errors import CapCutRunningError, ConfigError, ScriptError, VidflowError
from vidflow.project import Project
from vidflow.schema import Script
from vidflow.timeline import Timeline

SUB_STYLE = dict(size=8.0, color=(1.0, 1.0, 1.0), align=1, auto_wrapping=True)
SUB_Y = -0.7


def canvas_size(aspect: str) -> tuple[int, int]:
    return (1080, 1920) if aspect == "9:16" else (1920, 1080)


def capcut_running() -> bool:
    return subprocess.run(["pgrep", "-x", "CapCut"], capture_output=True).returncode == 0


def draft_name(project: Project) -> str:
    return f"vidflow_{project.root.name}"


def _stamp() -> str:
    return datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%S")


def _us(seconds: float) -> int:
    return round(seconds * 1_000_000)


def _range(start: float, end: float) -> cc.Timerange:
    return cc.Timerange(_us(start), _us(end) - _us(start))


def build_draft(project: Project, cfg: Config, script: Script, timeline: Timeline, *,
                is_running: Callable[[], bool] = capcut_running, stamp: Callable[[], str] = _stamp) -> Path:
    if is_running():
        raise CapCutRunningError("CapCut đang mở. Thoát CapCut (Cmd+Q) rồi chạy lại `vidflow build`.")
    if not timeline.scenes:
        reasons = "; ".join(f"{k}: {v}" for k, v in timeline.skipped.items()) or "script không có cảnh"
        raise VidflowError(f"Không có cảnh nào dựng được ({reasons})")
    if not cfg.draft_folder.is_dir():
        raise ConfigError(f"Không thấy thư mục draft CapCut {cfg.draft_folder}; đặt draft_folder trong vidflow.toml.")
    music_path = None
    if script.music:
        music_path = project.path(script.music.file)
        if not music_path.is_file():
            raise ScriptError(f"Không thấy file nhạc {script.music.file}")

    folder = cc.DraftFolder(str(cfg.draft_folder))
    name = draft_name(project)
    if folder.has_draft(name):
        shutil.copytree(cfg.draft_folder / name, project.backups_dir / stamp() / name)

    w, h = canvas_size(script.aspect)
    draft = folder.create_draft(name, w, h, allow_replace=True)
    draft.add_track(cc.TrackType.video)
    draft.add_track(cc.TrackType.audio, "voice")
    if music_path:
        draft.add_track(cc.TrackType.audio, "music")
    if any(p.subtitles for p in timeline.scenes):
        draft.add_track(cc.TrackType.text, "subs")

    style = cc.TextStyle(**SUB_STYLE)
    clip_settings = cc.ClipSettings(transform_y=SUB_Y)
    for p in timeline.scenes:
        target = _range(p.start, p.end)
        if p.clip_speed == 1.0:
            src_us, speed = target.duration, 1.0
        else:
            src_us = math.floor(p.clip_len * 1_000_000)
            speed = src_us / target.duration
        draft.add_segment(cc.VideoSegment(str(project.path(p.clip)), target,
                                          source_timerange=cc.Timerange(0, src_us), speed=speed,
                                          volume=p.clip_volume))
        if p.voice:
            draft.add_segment(cc.AudioSegment(str(project.path(p.voice)),
                                              cc.Timerange(_us(p.start), math.floor(p.voice_len * 1_000_000)),
                                              speed=p.voice_speed), "voice")
        for s in p.subtitles:
            draft.add_segment(cc.TextSegment(s.text, _range(s.start, s.end), style=style,
                                             clip_settings=clip_settings), "subs")

    if music_path:
        material = cc.AudioMaterial(str(music_path))
        total_us, t = _us(timeline.total), 0
        while t < total_us:
            d = min(material.duration, total_us - t)
            draft.add_segment(cc.AudioSegment(material, cc.Timerange(t, d), volume=script.music.volume), "music")
            t += d

    draft.save()
    state = project.load_state()
    state.draft_path = str(cfg.draft_folder / name)
    state.last_build_at = stamp()
    project.save_state(state)
    return cfg.draft_folder / name
```

```python
@command
def build(project: ProjectOpt, config: ConfigOpt = None):
    """Dựng draft CapCut Desktop từ clip đã chọn, voice-over, phụ đề, nhạc."""
    from vidflow.capcut_draft import build_draft
    from vidflow.media import probe_duration
    from vidflow.timeline import plan_timeline

    p = Project.open(project)
    cfg = load_config(config)
    script, state = p.load_script(), p.load_state()
    clips = {st.takes[st.picked].file for st in state.scenes.values() if st.picked is not None}
    tl = plan_timeline(script, state, {c: probe_duration(p.path(c)) for c in clips})
    for sid, why in tl.skipped.items():
        typer.secho(f"  bỏ qua {sid}: {why}", fg=typer.colors.YELLOW)
    path = build_draft(p, cfg, script, tl)
    typer.echo(f"Đã dựng {len(tl.scenes)} cảnh, {tl.total:.1f}s → {path}. Mở CapCut để xem.")
```

```markdown
# vidflow director

Bạn điều phối, không tự viết kịch bản/prompt: giao cho agent tương ứng. Mọi lệnh CLI: `uv run vidflow <lệnh> -p projects/<tên>`.

## Bắt đầu
1. Hỏi (nếu chưa rõ): ý tưởng, tỉ lệ 9:16/16:9, độ dài mong muốn, ngân sách USD.
2. `uv run vidflow new projects/<tên-không-dấu> --title "<tựa>" --aspect <tỉ lệ>`; đặt `budget_usd` theo người dùng.
3. Nếu project đã có: `uv run vidflow status -p ...` để biết đang ở cổng nào.

## Cổng duyệt (không bao giờ tự qua cổng)
| Cổng | Việc | Agent | Trình cho người dùng |
|---|---|---|---|
| 1 | Kịch bản | scriptwriter | Bảng cảnh: id, lời dẫn, thời lượng |
| 2 | Prompt + ảnh nhân vật | prompt-artist | Prompt từng cảnh, đường dẫn ảnh refs/, kết quả `vidflow estimate` |
| 3 | Voice-over | voice-agent | Danh sách file audio, thời lượng, cảnh báo dài |
| 4 | Gen video | video-producer | Đường dẫn `preview.html`, lỗi nếu có, chi phí đã tiêu |
| 5 | Dựng draft | editor | Tên draft CapCut, cảnh bị bỏ qua và lý do |

- Chỉ sang cổng tiếp theo khi người dùng nói rõ đồng ý (OK/duyệt/tiếp).
- Người dùng yêu cầu sửa → giao lại agent của cổng đó, chỉ chạy lại cảnh bị ảnh hưởng (`--scene`).
- Người dùng có thể bật "tự chạy" cho cổng 1, 3, 5; cổng 2 và 4 luôn phải duyệt.
- Trước cổng 4: đánh dấu `status: approved` chỉ cho cảnh người dùng đã duyệt (qua scriptwriter).

## Phản hồi giữa agent
- voice-agent/editor báo lời dẫn dài hơn clip → trình người dùng 2 lựa chọn: (a) scriptwriter rút gọn lời dẫn, (b) tăng `duration` cảnh lên 8s và gen lại. Làm theo lựa chọn.
- video-producer báo cảnh bị lọc an toàn → prompt-artist đề xuất prompt khác → quay lại cổng 2 cho cảnh đó.
- Lỗi `BudgetError` → báo người dùng, không tự tăng ngân sách.

## Báo cáo
Mỗi lần: một dòng đang ở cổng nào, việc vừa xong, việc cần người dùng quyết định.
```
